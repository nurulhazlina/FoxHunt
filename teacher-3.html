Element Length Formula — Full Derivation

The key formula for a half-wave dipole in free space:

λ = c / f = 300,000,000 m/s ÷ 144,000,000 Hz = 2.083 m (free space) λ/2 = 1.042 m = 104.2 cm With velocity factor for tape measure (steel, ~0.97): Driven element = λ/2 × vf = 104.2 × 0.97 = 101.1 cm (Physical measurement tuning gives 99.4 cm) Simplified formula: length_cm = 14300 / f_MHz → 14300 / 144 = 99.3 cm ✓ (matches within 1%) Element multipliers: Reflector = driven × 1.05 → 99.4 × 1.05 = 104.4 cm ≈ 104.0 cm Driven = 99.4 cm (tuned) Director = driven × 0.952 → 99.4 × 0.952 = 94.6 cm ✓
Key point for scouts: The reflector is longer than λ/2 so it reflects — it acts like a mirror for radio waves. The director is shorter so it "pulls" energy forward. The driven element is where the coax connects and is closest to λ/2.

Tier 1 — Fill-in-Blanks Answer Key

Q1. The tape-measure Yagi has ___ elements.
✓ 3 (accept: three)
Reflector + Driven Element + Director = 3 elements.
Q2. The longest element is the ___.
✓ reflector
Reflector = 104.0 cm. Driven = 99.4 cm. Director = 94.6 cm. Longest = reflector.
Q3. The reflector length for 144 MHz is ___ cm.
✓ 104 (accept: 104.0)
104.0 cm is the tuned reflector length for a 144 MHz tape-measure Yagi.
Q4. The driven element length is ___ cm.
✓ 99.4
99.4 cm — closely related to the half-wave dipole formula (14300/144 ≈ 99.3 cm).
Q5. Signal is strongest in the ___ direction of a Yagi.
✓ front (accept: forward)
The front lobe is the main beam. Signal is weakest at the sides (nulls) and moderately weak at the rear.
Q6. The Driven element is connected to the ___.
✓ coax (accept: coaxial cable, feedline, coax cable)
The driven element is the only element connected to the transmission line (coax). The others are parasitic.
Q7. When very close to the fox, switch to a ___ antenna.
✓ rubber duck (accept: omnidirectional, omni)
When within ~50 m, the Yagi's high gain makes it impossible to take a null bearing. A short omnidirectional antenna provides a manageable signal level.

Tier 2 — Debug Scenario Model Answers with Worked Solutions

Scenario 1 — Driven element 110 cm (too long)
Correct formula: length_cm = 14300 / f_MHz = 14300 / 144 = 99.3 cm
Worked solution:
Formula: λ/2 × vf = (c/f)/2 × vf = (300 × 10⁶ / 144 × 10⁶) / 2 × 0.97
= (2.083 / 2) × 0.97 = 1.042 × 0.97 = 1.011 m ≈ 101 cm
Practical tuned value: 99.4 cm (adjusted for tape width end effects)

The student's 110 cm is too long by ~11 cm. This lowers the resonant frequency below 144 MHz, causing high SWR at the operating frequency. Fix: Trim the element to 99.4 cm and re-check SWR.
Scenario 2 — Signal strongest pointing away from beacon
This is the body shielding technique (also called attenuator technique).
When very close to the fox (within 20–50 m), the forward signal from the Yagi is so strong that it saturates the receiver — every direction seems equally strong. By turning to face away from the fox, the scout interposes their body between the fox and the antenna. The human body absorbs ~10–15 dB of RF at 144 MHz. Combined with the Yagi's back lobe (~20 dB weaker than front), the total attenuation is sufficient to bring the signal back into the S-meter's linear range, allowing a precise null reading. Award marks for: naming the technique, explaining RF attenuation by body, and describing when it is appropriate.
Scenario 3 — Spacings reversed
Correct: Reflector → Driven = 36.5 cm; Driven → Director = 30.5 cm.
The director is shorter and placed closer to the driven element (30.5 cm) to achieve the phase relationship needed for forward gain. The reflector is longer and placed further back (36.5 cm). If reversed: the reflector is too close (acts more like a second director) and the director is too far back — the antenna would have poor gain and reversed directivity. Scouts should understand that spacing is not arbitrary: it sets the electrical phase delay between elements.

Tier 3 — Code Answer & Marking Criteria

Model Solution

function antennaPattern(angleDeg) {
  var rad = angleDeg * Math.PI / 180;

  // Front lobe: cos^4(angle/2) — peaks at 0°, zeros at ±180°
  // The power of 4 narrows the beam (higher = narrower)
  var front = Math.pow(Math.cos(rad / 2), 4);

  // Back lobe: ~1/100 of front (20 dB below = factor of 100 in power)
  // cos^4 of (angle-180)/2 gives a lobe centred at 180°
  var backRad = (angleDeg - 180) * Math.PI / 180;
  var back = 0.01 * Math.pow(Math.cos(backRad / 2), 4);

  // Return combined, clamped to 0–1
  return Math.min(1, Math.max(0, front + back));
}

// Verification:
// antennaPattern(0)   → ~1.00  (maximum forward gain)
// antennaPattern(90)  → ~0.00  (side null)
// antennaPattern(180) → ~0.01  (back lobe, ~20 dB below front)

Common Mistakes & How to Address Them

Confusing reflector and director positions

Scouts mount the director behind the driven element and the reflector in front. Fix: Memory aid — "the REflector REflects back, so it's at the REAR." The director is at the FRONT, pointing toward the fox.

Driven element cut too short

Scouts use formula 150/f or 300/f and forget the velocity factor, giving a driven element ~3–5 cm too short. Fix: Drill the formula: 14300 / f_MHz for tape-measure Yagi. Verify on a completed antenna with SWR meter before the field session.

Poor or cold solder joints on coax

Coax solder joints are often poorly made — cold solder causes intermittent connection and high SWR. Fix: Demonstrate the tin-then-join technique. Check by wiggling the coax while watching the SWR meter. Use heat shrink over all joints.

Elements not perpendicular to boom

Tape segments tilted at an angle reduce gain and shift the radiation pattern. Fix: Use a set square or a straight board as a guide when drilling/mounting. Check alignment visually from the front before the field session.

Switching to close-in technique too late

Scouts continue using the Yagi when very close to the fox, getting confused by signal-in-all-directions. Fix: Establish a "switch rule" — when S-meter is full on any bearing, switch to the rubber duck. Practice the switch before the field event.

Tips for Running the Build Session

  • Pre-cut the tape measure segments and label them (R/D/DE) to allow younger scouts to focus on assembly rather than measurement.
  • Prepare the PVC boom with holes already drilled for faster completion — scouts can still handle all other steps.
  • Have at least one completed, tested Yagi available to show as a reference and to demonstrate the signal pattern on an ARDF receiver.
  • For the SWR check, pre-calibrate one SWR meter per 4–6 scouts. Supervise transmit time — no more than 5-second bursts on low power.
  • After building, test each antenna outdoors: walk 30 m from a 144 MHz beacon and practice the slow-rotation technique before the full foxhunt.
  • Encourage scouts to mark "front" on the boom — a permanent marker arrow prevents confusion in the field.
Timing: Module 3 study: 20 min. Build session: 60–90 min. Field test: 20 min. Activities: 30 min. Total: ~2.5 hours (can split across two sessions).
